# 03: Recommended shows in the show directory

**What to build:** the show directory points out shows recommended for the listener, built from the recommendations of the shows they already follow.

**Blocked by:** 01

**Status:** needs-info

Open questions:

- Which shows feed it: subscriptions, shows played, loved episodes' shows, or a mix?
- How it looks: a "Recommended" section above the list, a filter, or a sort option?
- Seeding many shows means many Last.fm lookups. Should the lookups be spread out in the background, or should it only use what's already cached?
