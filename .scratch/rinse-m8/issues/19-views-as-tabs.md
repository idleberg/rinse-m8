# 19: Views as tabs

**What to build:** The single long page splits into views behind a nav. The **dashboard** is the default view and holds the subscribed episodes; the **schedule** view holds the schedule table. Both keep the shared filter bar. Opening a show still shows the show view, with the nav still visible; clicking a tab closes the show view. The theme toggle from 18 moves into the nav.
